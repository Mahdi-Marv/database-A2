# Database A2 — Time Series Similarity Search

This repository contains a practice lab for the M2 Data Acquisition, Extraction and Storage course at PSL. The goal is to find the closest match to a query time series and explore how to reduce the number of expensive distance calculations while still returning the exact nearest neighbor. The [student notebook](notebook_student_lab2.ipynb) follows the [assignment handout](topic_lab2.pdf) and generates a reproducible dataset of 1,000 time series with 256 observations each, along with four queries that include noisy, time-warped, and independently generated examples.

The lab starts with a brute-force search using Euclidean distance, then uses Piecewise Aggregate Approximation (PAA) to summarize each series with fixed-length segment averages. A lower bound computed from those averages can rule out candidates before the full distance is calculated. The next section introduces Dynamic Time Warping (DTW), which can align patterns that occur at different speeds or times, and examines how constraining the alignment affects both the nearest match and the cost of finding it.

The take-home exercises compare PAA with Adaptive Piecewise Constant Approximation (APCA), which uses variable-length segments. They also introduce LB_Keogh, a lower bound based on a query envelope, and an R-tree that groups PAA summaries so the search can skip entire branches. The final experiments compare brute force, a sequential scan with lower-bound pruning, and an indexed search by measuring how much work each approach does.

Open the notebook in Jupyter with NumPy and Matplotlib installed. The dataset is generated in the notebook, so there are no data files to download. The repository contains the starter notebook, including the data generator, R-tree construction helper, and reference checker. The main algorithms, proofs, and experiments are left as exercises. Use the default seed of 42 to compare completed answers with the reference values before switching to a personal seed.
